## 使用限制

- 参考图只固定层级、密度、状态表达和操作位置；不固定最终文案、数据、图标或像素。
- 施工时必须继续使用 Vuetify 和现有 Indigo/Roboto token。
- 参考图中的示例菜单可能因生成模型而出现旧名称或额外项；不得据此新增导航。
- 不把图片当作组件实现或无障碍验收依据；代码实现仍需覆盖键盘、缩放、窄屏、loading/error/empty/403 和减少动态效果。

## 生成方式

使用内置 `image_gen` 生成四张 `ui-mockup` 参考图，分别针对工作台、资源列表、资源详情/审计和系统配置；没有使用外部图片或项目用户数据。
