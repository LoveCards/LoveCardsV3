# Auth 行为基线

本文件记录 Auth 垂直切片开始前必须保持的行为。可执行基线位于
`apps/backend/tests/Auth/BehaviorBaseline.php`，通过以下命令运行：

```bash
cd apps/backend
composer test:auth
```

## 已锁定行为

| 场景 | 当前行为 |
| --- | --- |
| 用户不存在 | 登录失败，业务码 `1001` |
| 用户状态不是 `0` 或 `2` | 登录失败，HTTP 403，业务码 `1002` |
| 密码不匹配 | 登录失败，业务码 `1003` |
| 登录成功 | Token payload 包含用户 `uid` |
| 注册密码为空 | 注册失败，业务码 `9002` |
| 新用户用用户名注册 | `/session/register` 拒绝，既有用户名账号可继续登录 |
| 邮箱或手机号已存在 | 注册失败，业务码 `1004` |
| 注册成功 | 分配普通用户角色，状态为 `0` |
| 访客登录（每次调用） | 铸造独立的一次性访客身份；连续性由客户端持久化的 Token 承载 |
| 访客账号创建 | 创建访客角色账号，凭据完全随机（口令不经任何登录通道使用），状态为 `0` |
| 访客角色账号口令登录 | HTTP 403，业务码 `1101`，无论口令是否正确一律拒绝（中和存量弱口令访客行） |
| 持访客 Token 查询 `/session/check` | 响应 `visitor=true`，供客户端展示游客会话；服务端 `AuthContext` 仍保留持 Token 的账号身份和原有权限判断 |
| 登录连续口令失败达到阈值（IP+账号维度，或 IP 维度兜底） | HTTP 429，窗口内连正确口令也拒绝 |
| 访客铸造达到每 IP 小时限额 | HTTP 429 |
| 无 Token 且访客模式关闭 | HTTP 401，消息为“请先登入” |
| 无 Token 且访客模式开启 | 注入 `uid=0`、访客角色及访客能力 |
| 无效 Token 且访客模式关闭 | HTTP 401，并保留 Token 校验错误消息 |
| 无效 Token 且访客模式开启 | 降级为访客上下文 |
| Token 对应用户不存在 | HTTP 401，消息为“用户不存在” |
| 认证成功 | 注入包含 uid、用户、角色、能力及续期 Token 的 `AuthContext` |
| 访客认证 | 注入 `isVisitor=true` 的 `AuthContext` |
| capability 任一匹配 | 放行并将能力列表注入请求 |
| capability 全部不匹配 | HTTP 403，消息为“权限不足” |

## 注册方式与验证

在「系统 → 验证中心 → 验证要求」选择邮箱或手机号、仅邮箱、仅手机号。手机号当前支持中国大陆 11 位号码。邮件、短信验证分别作用于对应注册方式，图片验证码和极验按原有人机验证要求执行。

`user.registration_mode` 保存允许的方式，`user.captcha` 保留原邮箱验证开关，`user.registration_sms_verification` 控制短信验证。旧站未明确保存注册方式时，有邮箱验证要求的站点维持仅邮箱注册，其余站点允许两种联系方式。既有用户的账号、密码和登录标识沿用原数据。

`session.policy` 提供允许方式、验证码要求和本地配置就绪状态。`session.captcha` 与 `session.register` 根据同一份 Auth 策略判定方式并拒绝不匹配的请求。注册验证码绑定收件地址和 `Auth` 场景，有效期五分钟，六十秒后可重发，错误五次需要重新发送。发送受 IP 和收件地址两级额度限制。邮件与短信分别使用 Sender 的邮件和短信渠道，修改邮箱固定走邮件。渠道失败时，要求验证码的注册方式关闭提交；其他可用方式仍可使用。

沿用现有站点配置、缓存验证码、认证 API 和 Sender 测试。只新增两个配置键，无新表、API 路由、全局验证注册表或站内通知。阿里云短信模板的变量为 `code`，真实投递须用已审核签名和模板验收。

## 续期契约

过期 Token 只有在其续期凭据仍存在时才能续期。续期成功返回原认证数据和新 Token：

```php
['uid' => $uid, '_new_token' => $newToken]
```

续期会消费旧凭据，并由中间件在响应的 `X-New-Token` Header 中返回新 Token。续期凭据的
缓存时间为 Token 有效期加配置的续期宽限期；宽限期结束后，过期 Token 返回“token已失效”。
该行为由 `tests/Auth/JwtRenewal.php` 独立覆盖。
