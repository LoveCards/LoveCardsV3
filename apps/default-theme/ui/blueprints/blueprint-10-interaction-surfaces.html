04

Dialog System

所有离开文档流的任务共用三行骨架：Header、独立滚动 Body、固定 Footer。

FORM DIALOG · EDIT COMMENT

先稳定结构，
再承载状态。

错位不是视觉小问题，而是弹窗没有明确的滚动边界。标题、输入区和操作区必须各自拥有稳定的空间。

  1. 01
    Header标题、说明、44px 关闭按钮在同一行流中。
  2. 02
    Body只有正文滚动；错误、计数和辅助信息留在字段轴内。
  3. 03
    Footer操作栏不参与正文滚动，主动作始终可见。
