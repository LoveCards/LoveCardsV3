# Blueprint 01 · 首页信息流精简与 Apple 光学校准

日期：2026-08-13
状态：已应用到桌面与手机参考板

## 问题

第一轮精简虽移除了完整动态卡的冗余信息，但桌面仍是三列等权瀑布流：所有内容以相同音量竞争注意力，纯文字内容像孤立小组件，几何色块占位图也无法提供真实媒体应有的层次。界面变简单了，却没有形成系统级的视觉秩序。

## 决策

### 1. 桌面采用编辑式信息流

- 首屏设置一个横向主故事，明确第一视觉焦点。
- 随手记作为安静的文字副刊，与主故事并置，不伪装成图片卡。
- 图集、视频和讨论进入第二层，尺寸更小、权重更轻。
- 右侧使用单一 grouped surface 承载上下文，不拆成多张悬浮卡。话题行显示排名、讨论量和趋势信号；创作者行显示头像、领域说明与明确关注动作。组间依靠细分隔，整组按自身内容高度结束，不强行与信息流等高。

这不是把内容做成门户首页，而是在多列发现流中加入稳定的主次秩序；后续滚动仍可回到连续的发现节奏。

### 2. 手机保留小红书式双列扫描

- 手机不压缩桌面的编辑网格，独立使用双列瀑布流。
- 卡片顺序统一为媒体或文字表面 → 一至两行标题 → 作者、被动喜欢数、评论数与三点更多菜单。
- 卡片之间依靠留白区分，不增加常驻边框、阴影和完整操作栏。
- 文字卡使用短正文与轻轮廓，避免色块化，也避免与图片卡粘成一团。

### 3. Apple 式材质边界

- 内容层使用实心表面、中性画布、系统字体和稳定布局。
- Liquid Glass 只允许用于导航、浮层或临时控件，不进入普通内容卡。
- LoveCards 玫瑰色只用于选中态、主动作和状态提示，不装饰普通内容。
- 媒体圆角控制在 11–14px，仅使用半像素内描边；不叠加装饰性宽阴影。
- Hover 仅上移 1px，动效表达可点击状态，不做页面表演。

### 4. 真实媒体而不是几何占位

首页使用三组统一调性的真实生活媒体：海边晨光、城市漫游图集、晨跑视频封面。共同要求为自然光、低饱和、真实生活切片、可响应裁切，不包含品牌文字或 UI。WebP 文件总量约 0.54MB，原始 PNG 保留为设计源文件。

## Compact 卡信息边界

- 首页默认只保留被动喜欢数，不提供直接点赞按钮；喜欢进入详情，收藏、复制链接和举报进入三点更多菜单。
- 不在媒体上方重复作者头、时间和地点。
- 话题和摘要仅在确有识别价值时显示；标题承担主要判断任务。
- 详情页、关注流和讨论页继续显示完整上下文，不套用本次精简。

## 验收结果

- 桌面形成主故事、编辑札记、次级媒体和右侧上下文四级结构。
- 手机双列宽度约 156px，容器 `scrollWidth` 与 `clientWidth` 相等，无横向溢出。
- 移动底栏与内容区边界衔接，无覆盖。
- 三组媒体均正常加载，中文内容类型标签无乱码。
- 无控制台错误；减少动态偏好下关闭悬浮过渡。
