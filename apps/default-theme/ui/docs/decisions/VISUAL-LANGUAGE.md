# Blueprint 01 风格蒸馏与跨页面迁移规范

日期：2026-08-13
状态：Blueprint 01–09 与系统状态板的共享视觉基线

## 一句话定义

LoveCards 是一套以真实内容和社区关系为中心的系统级界面：像 Apple 产品一样把 UI 退到任务之后，用稳定的光学秩序承载小红书式发现效率与 X 式关系上下文。

## 六条不可变规则

1. **内容先于容器**：图片、文字、关系和讨论决定轮廓，不先画万能卡片。
2. **实心材质优先**：内容、表单和侧栏使用不透明 Surface；玻璃只属于媒体上的临时控制。
3. **中性系统 + 玫瑰状态轴**：冷中性画布承载页面，玫瑰色只表达主动作、当前选择和关系反馈。
4. **同心几何**：控件 8–10px、媒体 12px、面板 14px；头像与短标签才使用全圆。
5. **分隔优先于阴影**：常驻区域通过色调、留白和半像素轮廓分层；宽阴影只属于真正浮层。
6. **响应式是重组**：桌面利用上下文栏和工作区，手机重新排序为当前任务，不缩放桌面页面。

## 页面族迁移方式

| 页面族 | 保留的结构 | 迁移的视觉语法 |
|---|---|---|
| 首页/发现 | 编辑式主故事、双列发现流 | 真实媒体、紧凑元数据、单 grouped 上下文栏 |
| 搜索/话题 | 搜索任务、最佳匹配、连续结果 | grouped list、低噪声筛选、统一身份行 |
| 内容详情 | 单一阅读轴、讨论线程 | 实心正文、媒体控件材质、细分隔评论 |
| 发布/草稿 | 分步编辑、媒体投放、发布检查 | 中性编辑表面、一个主动作、内联状态 |
| 用户中心 | 身份头、关系数据、内容资产 | 真实封面媒体、统一按钮、grouped 辅助栏 |
| 身份/关系/安全 | 表单、关系列表、分级危险操作 | iOS 式 grouped rows、实心字段、危险色仅用于动作 |
| 消息/通知 | 桌面双栏工作区、移动独立会话 | 连续列表、轻未读状态、克制气泡和固定输入区 |
| 资产/设置 | 分类入口、设置列表、开关 | grouped list、统一行高、玫瑰选中态 |
| 登录/恢复 | 单任务表单、恢复步骤 | 中性画布、可信表面、无装饰性渐变 |
| 系统状态 | 真实骨架、恢复动作、权限说明 | 同一 Surface、状态色和圆角，不做万能空卡 |

## 被移除的复杂度

- 不再维护每个页面一套略有差异的画布、灰色、玫瑰色和圆角值。
- 移除装饰性玻璃、渐变按钮、宽阴影与“每个区块都是卡片”的默认反应。
- Blueprint 03 的历史探索只保留在归档记录中，不进入正式总览；正式迁移只面向注册表入口。
- 不把首页三列或双列结构复制到阅读、消息、设置和认证页面。

## 工程入口

所有正式蓝图在页面专属 CSS 之后加载 [`../../blueprints/visual-language.css`](../../blueprints/visual-language.css)。页面专属样式负责信息结构；共享迁移层负责材质、Token、状态和光学校准。
