# Blueprint 03 完整响应式方向

日期：2026-08-12
状态：已确认方向；作为内容详情页面家族的后续设计基准。

## Current composition

- 桌面端沿用 Airy Solid 双列详情：连续内容与讨论为主列，作者、话题和继续浏览为辅助上下文。
- 移动端沿用 Mobile Reading Structure：内容主体、四等分操作栏、讨论区三个明确任务段。
- 两端共享色彩、字体、圆角、线条和评论线程语义，但允许响应式结构重组。
- 评论保持连续线程，不使用一条评论一个卡片的结构。
- 透明材质仅允许出现在媒体控制等必要浮层，不作为内容容器材质。
