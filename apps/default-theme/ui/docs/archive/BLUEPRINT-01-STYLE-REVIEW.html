风格蒸馏与跨页面迁移规范

LoveCards 是一套以真实内容和社区关系为中心的系统级界面：像 Apple 产品一样把 UI 退到任务之后，用稳定的光学秩序承载小红书式发现效率与 X 式关系上下文。

六条不可变规则

  1. 内容先于容器：图片、文字、关系和讨论决定轮廓，不先画万能卡片。
  2. 实心材质优先：内容、表单和侧栏使用不透明 Surface；玻璃只属于媒体上的临时控制。
  3. 中性系统 + 玫瑰状态轴：冷中性画布承载页面，玫瑰色只表达主动作、当前选择和关系反馈。
  4. 同心几何：控件 8–10px、媒体 12px、面板 14px；头像与短标签才使用全圆。
  5. 分隔优先于阴影：常驻区域通过色调、留白和半像素轮廓分层；宽阴影只属于真正浮层。
  6. 响应式是重组：桌面利用上下文栏和工作区，手机重新排序为当前任务，不缩放桌面页面。

被移除的复杂度

  • 不再维护每个页面一套略有差异的画布、灰色、玫瑰色和圆角值。
  • 移除装饰性玻璃、渐变按钮、宽阴影与“每个区块都是卡片”的默认反应。
  • 旧 Blueprint 03 V2–V5 保留为探索档案，不进入正式总览。
  • 不把首页三列或双列结构复制到阅读、消息、设置和认证页面。

工程入口

所有正式蓝图在页面专属 CSS 之后加载 visual-language.css。页面专属样式负责信息结构；共享迁移层负责材质、Token、状态和光学校准。
