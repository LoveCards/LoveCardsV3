# LoveCards 界面动效规范

> 状态：v1.4，交互与动效设计基线；适用于默认主题的阅读预览层、情境登录、弹窗、页面、Tab 与组件状态。数值与曲线只由 [`DESIGN.md`](../../DESIGN.md) 的 `motion` Token 定义，基础使用规则见 [`FOUNDATIONS.md`](../../standards/FOUNDATIONS.md)。本文件定义何时运动、运动哪一层及如何验收，不表示运行代码已经完成迁移。

## 1. 总原则

- 动效只帮助用户判断状态变化、层级关系和内容身份，不为每次点击添加装饰。导航提交、数据请求、焦点与读屏反馈不等待动画。
- 转场只影响发生变化的表面。全局顶栏、BottomNav、页面标题、身份头和固定操作区保持稳定；加载、空、失败、权限与成功态占用同一内容区域。
- 位移仅使用 `transform`，淡化仅使用 `opacity`；状态色可过渡 `color`、`background-color` 和 `border-color`。不动画 `width`、`height`、`top`、`left`、`margin`、网格轨道或内容滚动位置。不得用模糊、弹跳、橡皮筋或长距离飞入制造深度。
- 同一交互重复触发、反向操作或路由离开时，当前动画须被取消或从当前视觉状态反向过渡；不能排队播放，也不能显示旧数据的最后一帧。
- 有效减少动态效果 = 系统偏好或站内设置任一开启。此时空间位移、缩放、内容淡化、循环 Skeleton 闪烁均关闭，状态即时落定；加载与错误文字仍正常可见。
- 信息流和详情的骨架在等待数据时沿同一透明度节奏轻脉冲；懒加载路由的中性提示显示旋转加载标记。内容就绪后由原内容区承接，不能为了展示加载动画而延迟请求或渲染。减少动态效果时保留静态骨架和加载文字。
- 所有需要异步代码或数据的高频动作，在激活后的下一次可绘制帧呈现可见反馈：触发器按下态、目标表面的加载态或明确的提交状态。阅读层外壳和关闭入口不能等待详情模块或网络请求；加载态应保留目标卡片类型的基本几何和可见文字。预取只缩短等待，不能作为反馈的唯一保证。减少动态效果仅移除运动，不移除反馈。

## 2. 场景矩阵

| 场景 | 进入 / 切换 | 退出 / 反向 | 保持不动的层 |
|---|---|---|---|
| 桌面 Form / Alert Dialog | Surface 从 `motion.dialogLift` 的下方平移并淡入，使用 `motion.control`；不缩放 | Surface 淡出并回到同一偏移，使用 `motion.state` | 背景页面、Dialog 内 Header / Body / Footer 的相对位置 |
| 手机 Form Sheet | 从底边向上 `motion.sheetLift` 并淡入，使用 `motion.control` | 向底边淡出，使用 `motion.state` | Header、Body、Footer 的布局与安全区 |
| Backdrop | 与 Surface 同时开始，透明度用 `motion.state` 到目标遮罩色 | 与 Surface 同时开始并淡出，使用 `motion.state` | 背景页面的布局与滚动位置 |
| 全屏任务层 | 任务表面直接出现；必要时仅内部内容用 `motion.state` 淡入 | 直接关闭；不做整屏平移 | 原页面与返回目标 |
| 一级页面及普通路由 | URL、壳和焦点即时更新；仅新内容区从 `motion.contentLift` 淡入，使用 `motion.state`，已有内容退出不等待动画 | 返回恢复滚动与筛选；若目标已可见，跳过入场 | 全局导航、页面标题、固定操作区 |
| 卡片打开阅读预览层 | 同一媒体可可靠匹配时以 `motion.matchedExpand` 连续展开；否则媒体阅读层从来源方向有限放大，文字阅读层短上浮；Backdrop 用 `motion.state` | 关闭沿当前表面轨迹退出，返回时恢复来源滚动 | 原 Feed DOM、筛选、列宽和滚动位置 |
| 同页 Tab | 选中指示器沿标签栏移动，使用 `motion.state`；目标内容在原内容区就绪时短淡入 | 反向切换遵守相同规则；连续切换只显示最新结果 | 页面壳、身份头、Tab 栏、Feed gutter |
| 锚定菜单 / Popover | 以触发器为锚，从 `motion.contentLift` 淡入，使用 `motion.state`；关闭反向淡出 | 锚点失效、滚动离开或路由变化时即时清理 | 触发器与背景布局 |
| Press / Hover / Focus / Like / Save | 按下用 `motion.press`；色彩、图标和计数的状态反馈用 `motion.state`，失败回滚沿同一路径 | 可中断并回到当前真实状态 | 周围布局与文字行高 |

上述时长是上限，不得为了凑满时长延迟交互。已有浏览器原生滚动或操作系统导航手势由平台负责，应用不叠加第二层同方向动画。

## 3. 弹窗时序与语义

标准 Dialog、Alert 与情境登录沿用 [`DIALOGS.md`](./DIALOGS.md) 的结构和关闭规则。手机响应式 Form Sheet 使用本规范的 Sheet 轨迹；Alert 在手机仍是居中确认框时使用 Dialog 轨迹。禁止仅凭视口宽度把所有 Alert 变成 Sheet。

1. 打开时先建立模态语义、锁定背景滚动并安置初始焦点，再播放 Surface 与 Backdrop。入场期间按钮可操作；立即关闭应中断入场并开始退场。
2. 用户请求关闭且当前任务允许关闭时，阻止重复关闭和退场期间的新提交，播放退场；在退场结束后关闭原生 Dialog、解除滚动锁并按 [`DIALOGS.md`](./DIALOGS.md) 恢复焦点。动效期间模态层仍拦截背景交互。
3. 路由离开或触发器卸载时直接清理模态层，不等待计时器；焦点落到仍存在的合理目标。减少动态效果在入场中途开启时，打开态立即稳定；在退场中途开启时，立即完成关闭。提交中的禁止关闭规则优先于动画。
4. Backdrop 是中性遮罩，只改变透明度，不添加额外模糊动画。软键盘、动态视口和 safe-area 变化应立即重新排版，不通过位移动画追赶键盘。

Astryx 当前版本的 Dialog 入场时长、曲线、缩放与本规范不同，且关闭为即时行为。落地时只在共享 Dialog 适配层处理这一差异，不复制一套焦点陷阱、Portal 或原生 Dialog 实现；无法安全保持关闭期模态语义时，先即时关闭，不用延时卸载伪造退场。

情境登录沿用桌面 Form Dialog / 手机 Sheet 的轨迹，不新增独立时长或弹性动效。预览层中触发登录时，登录表单在现有阅读区原位展开，使用 `motion.state` 淡入；阅读层和 Backdrop 不再播放第二次入场。取消时局部收起并恢复原动作焦点；转完整登录页时按普通路由内容区入场，不把弹窗快照飞入页面。

## 4. 页面与 Tab 的边界

一级入口、设置栈、关系页和消息会话保持 [`NAVIGATION.md`](./NAVIGATION.md) 的路由、Shell、历史与返回契约。普通路由不定义统一的“前进右滑 / 返回左滑”，也不缓存上一页截图等待转场。只有目标内容区首次出现且已准备好时，应用 `motion.state` 的短淡入与 `motion.contentLift`；若是 Skeleton，Skeleton 占位原位显示，数据就绪后内容在原几何位置淡入。返回已保留的视图、锚点跳转、提交后需要立即读到结果的反馈跳过内容入场。所有内容区入场都不能延迟 URL、焦点、读屏通知或可点击状态。

个人主页“内容 / 喜欢 / 收藏 / 历史”属于同页视图切换：点击或键盘激活后立即更新 URL、选中态和可访问状态，只替换 Feed 内容；方向键、Home/End、焦点与面板关联按 [`NAVIGATION.md`](./NAVIGATION.md) 执行。消息中心“私信 / 通知”使用不同 path，保留 Link 语义和同一视觉外壳；跨路由时选中标记即时落位，工作区可以做局部淡入，不做横向飞入。不得仅为指示器动效重建消息中心路由壳。

标签栏横向溢出时允许手指自然滚动，并确保当前项可见；这是**滚动标签栏**，不等于在内容上左右滑动切 Tab。当前不启用内容区滑动手势：Feed 媒体横滑、页面纵滚、浏览器返回手势与其存在冲突。未来若增加手势，必须先在导航规范中确定命中区域、方向锁定、取消阈值、URL 历史和异步加载，再作为独立交互任务设计。

## 5. 阅读预览层的连续展开

阅读预览层的结构和适用场景由 [`DIALOGS.md`](./DIALOGS.md) 定义，URL 与返回由 [`NAVIGATION.md`](./NAVIGATION.md) 定义。这里仅规定动效轨迹：

1. 点击卡片媒体或文字主表面后，先保留来源 Feed 的 DOM 和滚动位置，再提交 `/post/:id`。来源表面与预览层中的同一媒体或文字容器之间使用 `motion.matchedExpand`，匹配圆角与裁切；阅读文字本身不做缩放，只在目标容器就位后以 `motion.state` 显示。Backdrop 同步淡入，预览层的作者、正文、讨论与操作随后在原位淡入。
2. 仅当前一次激活的卡片有匹配名称。图集匹配当前封面，视频匹配静态海报；预览层就位后视频在原画框尝试静音内联播放，浏览器拒播时显示原位播放按钮；正在播放的视频先暂停并保存播放状态，不能把真实视频帧放大。图片未解码、来源离屏、资源身份改变、目标未就绪或浏览器不支持可靠匹配时，不使用媒体匹配名。媒体阅读层可从仍可见的来源方向进行小幅位移和缩放，文字阅读层只上浮淡入；来源不可定位时从默认位置入场。此退化轨迹不声称同一媒体连续匹配，不能让表面飞向错误卡片。
3. 关闭时沿已选择的表面轨迹退出，来源页在原滚动位置恢复。快速打开/关闭、换卡和浏览器前进/后退应取消旧转换，只以最新 URL 和资源为准；动画快照不接受交互，真实模态层在整个过程中负责焦点与背景阻断。
4. 站内或系统减少动态效果开启时，匹配缩放、内容位移和淡化均跳过；资源、URL、焦点、滚动及关闭语义不变。不能为制造连续感而拖慢导航、等待网络图片或让空白面停留。

Web 平台支持时可用同文档 View Transition 对唯一匹配元素做渐进增强；同名元素在转场前后都必须唯一，使用后清除临时匹配名。不支持或冲突时走上述无匹配回退。不得在各个卡片里维护独立的 FLIP 坐标与计时器。

## 6. 其他状态与克制边界

- Like、Save 与 Follow：图标填充、颜色和计数在原热区内过渡；乐观更新失败沿相同状态轴回滚并给出文字反馈。计数变化不推动相邻控件横跳。
- 搜索建议、通知菜单和更多菜单：使用同一个锚定浮层轨迹；结果更新只替换列表内容，取消旧请求。Toast 只提示结果，不接管焦点，不把成功反馈改为第二个 Dialog。
- Skeleton 到内容：保持同一几何，内容就绪时短淡入；加载更多只影响尾部新项。新卡不逐张弹跳，长列表不在滚动时集体入场。
- 媒体查看器、发布、私信会话和设置分类保持任务表面；桌面发布 Dialog 使用共享 Dialog 的短上浮和遮罩淡入，手机发布页使用普通任务页入场，不让整个屏幕水平滑行。
- Hover 和 Focus 的状态反馈不得只靠缩放。Focus ring 必须即时可见，动效只能修饰颜色或背景，不能延迟可访问焦点。

## 7. 工程落地约束

- `DESIGN.md` 的 `motion` 值映射到 [`FOUNDATIONS.md`](../../standards/FOUNDATIONS.md) 所列运行时 Token；页面样式和共享组件只引用 Token。不得在每个页面分别声明 Dialog、Tab 或路由 keyframe。
- 优先复用 Astryx 的行为与语义。若核心组件不能满足本规范，先通过薄适配层验证其开放 API；不能用全局 `!important` 或任意计时器覆盖焦点和卸载流程。
- Dialog、Tab 与路由的共享动效和减少动态效果规则由各自共享层定义；页面局部状态可引用同一 Token，不复制共享 keyframe 或写入无名时长。
- dev 当前实施状态及未验收场景记录在 [`MOTION-IMPLEMENTATION-PLAN.md`](../implementation/MOTION-IMPLEMENTATION-PLAN.md)；本规范的验收矩阵仍作为完成门槛。

## 8. 验收矩阵

| 场景 | 必检结果 |
|---|---|
| 弹窗快速开关、连点与路由离开 | 无残留 Backdrop、滚动锁、焦点陷阱、旧内容闪现或重复提交；允许关闭时最终焦点合理 |
| 桌面 Dialog / 手机 Sheet | Surface、Backdrop 同步开始且各自按 Token 完成；Header、Body、Footer 不跳位；320px、390px、软键盘与 safe-area 可用 |
| 普通路由与浏览器返回 | URL / 焦点即时正确；无整页飞入、空白帧或历史错位；原滚动与筛选按导航规范恢复 |
| 信息流卡片到预览层 | 匹配身份、裁切和圆角连续；文字可读；未就绪、离屏、视频、减动各有正确回退；关闭后来源 Feed 与筛选、滚动不丢失 |
| 慢模块与慢数据 | 点击后的下一帧有按下或加载反馈；延迟详情模块时预览外壳、关闭入口及加载文字仍可见；完成后在同一表面替换内容，无空白等待 |
| 预览层历史与深链 | 卡片打开、关闭、Back/Forward、刷新、直接访问、修饰键/新标签、完整详情入口的 URL 与表面符合导航规范；焦点和滚动锁无残留 |
| 情境登录与独立认证页 | 弹窗内可完成登录；失败保留输入；成功恢复来源与会话；注册/恢复/深链仍进入独立页面；预览层内联登录时始终只有一个模态焦点范围 |
| 发布入口 | 桌面站内打开宽 Dialog，手机和直达进入独立页；共用编辑轴，来源返回、脏状态确认、成功/失败与减动保持一致 |
| 锚定菜单与即时动作 | 菜单位置稳定且不遮挡触发器；Like/Save/Follow 连点、失败回滚和计数变化不产生布局跳动 |
| Tab 点击、键盘、前进后退 | 选中态与 URL 同步；指示器运动可中断；内容只在原区域更换；Skeleton、空、错、权限态不改变页面壳 |
| 标签栏横向滚动 | 当前项可见且不强制平滑滚动；在内容上横滑不误切 Tab；媒体横滑与系统返回手势不被拦截 |
| 系统或站内减少动态效果 | 位移、缩放、内容淡化、Skeleton 闪烁均消失；状态、焦点、滚动锁与关闭行为仍完整 |
| 慢设备与亮暗主题 | 反复交互无显著布局抖动、层级闪烁或主题瞬态错色；动画不阻塞操作 |
