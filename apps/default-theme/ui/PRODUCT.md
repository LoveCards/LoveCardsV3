# Product

## Register

product

## Users

以图片、视频和短文本分享兴趣与生活的社区用户。他们在手机或桌面端浏览信息流、参与讨论、维护关系并管理个人内容。

## Product Purpose

LoveCards 以分享为第一优先级，融合小红书的视觉发现与 X 的讨论效率，逐步承载社交、养成和社区生态能力。成功意味着用户能从发现内容到互动、发布和关系沉淀形成可信且连贯的闭环。

## Brand Personality

清新、灵动、克制。界面应具有 Apple 产品的秩序与精度，同时保留社区内容本身的张力。

## Anti-references

避免老套玻璃拟态、松散的万能白卡、工程测试台、营销型首页、无依据的假数据与假成功，以及为了风格而重新发明标准交互。

## Design Principles

1. 内容优先，界面退后。
2. 熟悉的交互必须符合直觉，状态变化必须可见。
3. SDK 有能力就完整接入，没有能力就诚实说明边界。
4. 手机与桌面共享语义，但允许结构性重排。
5. 先沉淀设计规范，再实现可复用交互。

## Accessibility & Inclusion

核心路径以 WCAG 2.1 AA 为基线，支持键盘、读屏、清晰焦点、至少 44px 触控目标、减少动态效果和不依赖单一颜色表达状态。
