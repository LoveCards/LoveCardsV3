# Design System

The canonical visual specification is [ui/DESIGN.md](ui/DESIGN.md). It remains under `ui/` so the runnable SPA and designer-facing references keep a clear boundary.

Implementation must follow the canonical “LoveCards System Material Feed” tokens and rules: opaque content-first surfaces, cool neutral canvas, accessible deep rose actions, one system sans family, 12-16px content radii, 150-250ms state motion, and responsive structures for desktop, tablet, and mobile.
